Not cool. Not warm. Correct.

Her shoes should have clicked.

They did not.

03 · Why this direction

Index

Index treats the reader like a precise instrument. Structure comes entirely from a hairline grid — no shadows, no fills, no rounded blobs. Grotesk type handles the interface while monospace carries every number (progress, page, counts), so data always looks like data. The page art is the only colour; everything else is ink on cool white.

  • 01Continue is the first block with a solid-ink "Resume reading" button — the one unmissable action on Home.
  • 02A stat strip replaces the cramped ring — three monospace figures (min today, finished, in library) read instantly.
  • 03Library becomes a clean data list with monospace tags and counts on every filter, so the catalogue feels indexed.
  • 04The reader shows a segmented progress strip and a single PAGE 01/14 — no duplicate counters, no floating circles.
  • 05Desktop scales into a true two-column grid (list + detail) — the hairline system fills wide canvases without dead space.
